# Code of conduct

## The short version

Be decent to people here. Disagree with code and ideas all you want. Leave the person out of it.

## What that means in practice

Review comments talk about the change in front of us. Questions are welcome at any level. Nobody gets mocked for not knowing a tool yet, because everyone started somewhere with every tool in this stack.

Harassment, personal attacks, and slurs have no place in issues, pull requests, or any project space. Neither does publishing private information about another person.

## Enforcement

The project maintainer reads reports sent through GitHub and acts on them. Actions range from a quiet word to removing comments to blocking an account from the project, matched to how serious and how repeated the behavior is. Decisions aim to keep the space usable for the people doing the work.

## Scope

This applies in every space tied to this repository, including issues, pull requests, discussions, and commit threads.
